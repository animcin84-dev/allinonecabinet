# Проверка frontend Allinone

Обновлено 17 октября 2026. Проверена production-сборка на локальном preview 127.0.0.1:4319. 17 октября кабинет также опубликован и адресно проверен на Vercel.

## Автоматические проверки

`npm run check` — успешно. `npm test` — **125 тестов в 22 файлах**, все пройдены. `npm run build` — успешно. `npm run report:bundle` — бюджет выполнен. Проверка зависимостей npm audit ранее дала 0 известных уязвимостей; она не повторялась в этом проходе и не заменяет аудит безопасности.

Проверяются цикл задачи и XP, отсутствие начисления до Review и дублей после повторного решения, сохранение старых отправок, запрет собственной проверки, причины возврата/корректировки, роли и области чтения/действия, 401/403/409/503 и сохранение ввода. Новые тесты покрывают создание/архив проектов и команд, запрет удаления активного исполнителя, редактор задачи, независимость команд от проектного доступа, комментарии/checklist и ревизии, безопасные ссылки, приватность материалов и портфолио, месячное закрытие и повторную операцию, ручной ранг.

Анкета: 22 вопроса, условия департаментов/приоритетов, полная отправка, черновик/ошибка и перенос старых заявок. Миграции не уничтожают XP/решения и отказывают при повреждённых вложенных записях или будущей схеме. Файлы: форматы/размеры/сигнатуры, локальная обработка, commit хранилища, отсутствующий blob и preview. Сценарий потери несохранённой редакции проверен с настоящим router blocker. История изменения категории не выводит технические ID или ложное изменение эквивалентной даты.

Графики/периоды/таблицы и дневные границы Алматы, положительные/отрицательные корректировки, начальная/историческая зона времени, сохранённые фильтры с allowlist, clipboard pending/отказ/успех и доступные имена полей также покрыты тестами. Тесты не являются доказательством работы настоящего сервера.

## Браузерные сценарии

В текущей сборке проверены:

- создание явно демонстрационной встречи через интерфейс и наличие записи после refresh;
- загрузка локального тестового PNG, обработка JPEG-аватара, сохранение профиля и наличие загруженного изображения после refresh;
- добавление комментария и пункта checklist, отметка выполнения, сохранение обоих после refresh;
- редактор подтверждённой задачи: награда/исполнитель/проект заблокированы; изменение категории сохраняется и получает понятную историю;
- попытка перехода из изменённого редактора: диалог, возврат к введённому и успешное сохранение;
- RU/ҚАЗ на эквивалентной карточке; контент пользовательского комментария при смене языка не переводится автоматически;
- мобильные фильтры календаря на 390 px: полные подписи и режим повестки вместо узкой сетки;
- казахский календарь: 320/390/430/768/1024/1440 px, ширина документа соответственно 305/375/415/753/1009/1425 px при системной полосе прокрутки; внешнего горизонтального overflow нет;
- отсутствие console error в проверенных вкладках финальной сборки.

Демонстрационные запись встречи, комментарий/checklist и фото добавлены исключительно в локальной QA-вкладке. Обновление страницы не сбрасывало существующий набор. Перестройка dist требовала обновления вкладки со старыми hashed chunks; для такого отказа интерфейс содержит действие «Обновить страницу».

Доказательства: `plan-calendar-desktop.png`, `plan-calendar-mobile.png`, `plan-calendar-mobile-kk.png`, `plan-release-overview.png`. Предыдущие `overview-final*`, `ui-polish-*`, `experience-*` и мобильные proof показывают ранние проверки цикла отправка → возврат → повтор → подтверждение, +10 XP, навигации клавиатурой, диалогов, графика, clipboard и reduced motion. В дополнительном проходе на отдельном origin 127.0.0.1:4320 вручную пройден полный путь: четыре шага анкеты и локальный PNG → отправка → запрос уточнения → повторная отправка → принятие с кором → назначение проекта через участника → наличие в составе проекта → создание задачи → начало → отправка → возврат с причиной → повторная отправка → подтверждение → одна запись +10 XP. После reload история XP сохранилась; прямая ссылка принятого кандидата больше не теряется во время загрузки роли.

## Размеры сборки

Числа берутся из Vite manifest и локальных gzip byte lengths; общие static imports считаются один раз:

| Часть | Размер |
|---|---|
| Начальный JS обзора | **196 573 bytes gzip**, бюджет 200 000 выполнен |
| Начальный CSS | 14 942 bytes gzip |
| Подробный график | 109 305 bytes gzip дополнительно, лениво |
| Упомянутые WOFF2 | 142 156 bytes, верхний набор файлов; не фактический сетевой расход |

MSW исключён из production-пути. Мутационный движок, календарь, формы, материалы и диалоги загружаются по требованию. Vite предупреждает о главном чанке >500 KB в несжатом виде; предупреждение не скрыто. Неоднозначные PURE-комментарии Zod удалены Rollup; сборка успешна. Эти числа не измеряют внешнюю задержку, Lighthouse, LCP или INP.

## Архив и границы приёмки

ZIP пересобран из текущего `dist`, проверены CRC, соответствие файлов, вложенные assets из manifest и присутствие семи лицензионных файлов. `index.html` и `_redirects` находятся в корне. Исходники, localStorage, IndexedDB, личные документы и QA-скриншоты не входят. Предыдущая контрольная версия сохранена отдельно.

Не проверены в текущей среде: реальные Safari/iOS/Android, screen reader, zoom/текст 200%, полный WCAG, весь набор страниц во всех ориентациях, большой синтетический набор и лабораторные показатели загрузки. Казахская редактура требует носителя. Внешний сайт Framer прочитан отдельно; отсутствие публичного переключателя языка/фильтров остаётся открытым пунктом. До настоящих аккаунтов нужны отдельный API и серверная проверка доступа.
