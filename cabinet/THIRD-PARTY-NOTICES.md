# Third-party component adaptations

Allinone frontend includes selective local adaptations and design patterns from the user-supplied source archives below. Full upstream license text is retained in licenses/. The same notices are shipped in public/licenses/ for static distribution. Installed dependencies retain their own package licenses.

- Magic UI — MIT; Copyright (c) Magic UI. Number Ticker / Blur Fade adapted for actual-value initialization, accessible static values, local typography, locale and reduced motion.
- Cult UI — MIT; Copyright (c) 2023 Jordan-Gilliam. Animated Number spring pattern adapted for locale, finite-value handling and reduced motion.
- shadcn/ui — MIT; Copyright (c) 2023 shadcn. Base UI Tabs composition adapted to the local design system and URL-controlled selection.
- Base UI — MIT; Copyright (c) 2019 Material-UI SAS. Animated tabs indicator pattern adapted; existing installed Base UI supplies semantics.
- EvilCharts — MIT; Copyright (c) 2026 Gurbinder. Monospace bar chart, hover trace and tooltip presentation patterns adapted to existing Recharts, signed XP data, keyboard/touch controls and local style.
- Spectrum UI — Apache License 2.0; attribution follows the supplied LICENSE. MODIFIED: Notification Bell pendulum/count pattern and loading-button behavior rewritten within Allinone local components using motion/react-m, selected Solar icons, RU/KK labels, actual unread-count changes, actual pending state, and both reduced-motion preferences. Original Next/Radix application and catalogue dependencies are not included.
- Ruixen UI — MIT; Copyright (c) 2025 Ruixen UI. Button Copy adapted to the existing Button, Promise-based success/error feedback, timer cleanup and reduced motion; original audio/blur behavior removed.

Not all uploaded libraries are included. See UI-LIBRARIES-RU.md for the full selection rationale. Additional screenshots, data and brand assets remain governed by their original owners; these component licenses do not relicense those materials.
