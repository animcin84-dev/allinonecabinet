# UI-библиотеки: отбор и интеграция в Allinone

Проверены все 16 предоставленных архивов: состав, manifest, лицензии и исходники подходящих компонентов. Скрипты из архивов не запускались. Версии в них — предоставленные снимки, не заявление о последних релизах. Новые зависимости не добавлены; React 19, Tailwind 4, Base UI, Motion и Recharts уже были в кабинете.

## Что теперь работает

- **Magic UI + Cult UI:** плавное обновление настоящих чисел XP и статистики через MotionValue. Первый показ сразу содержит актуальное число; экранный диктор получает итог, а не каждый кадр. Переход страницы — короткое появление с перемещением на 8 px, без размытия.
- **Base UI + shadcn:** вкладки проекта с доступной семантикой, клавиатурой, сохранением выбора в URL и движущимся индикатором. Стрелки меняют фокус; Enter выбирает вкладку. На мобильном вкладки доступны без изменения всей страницы.
- **EvilCharts:** визуальная композиция существующего Recharts-графика — итоговые начисления, корректировки и баланс, компактная подсказка, чёткая нулевая линия. На главной можно выбрать период касанием или клавиатурой. Положительная корректировка находится выше нуля, отрицательная — ниже; масштаб общий. Числовая таблица сохранена.
- **Spectrum UI:** колокольчик реагирует однократно на реальный рост непрочитанных сообщений. Локальная кнопка показывает состояние ожидания настоящей операции и блокирует повторное нажатие.
- **Ruixen UI:** копирование ссылки проекта/задачи с подтверждением после успешной записи, сообщением при отказе браузера и очисткой таймера. Звук не используется.
- **Allinone:** сохранены фирменные цвета, шрифты и структура. Уточнены состояния карточек, боковая навигация, чекбоксы, кнопки, этапы задачи и подтверждения. Три шеврона связывают акцентный блок с фирменными постами.

Это адаптация выбранных компонентов и визуальных приёмов в существующую систему, а не подключение целых библиотек. Модель задач, балансов и ролей остаётся владельцем данных.

## Правила движения

Переход страницы 280 ms, вкладка 220 ms, панель 180 ms, график 360 ms, короткий колокольчик 600 ms только по событию. Преимущественно transform/opacity. Нативная прокрутка; нет постоянного WebGL, перехвата курсора, GSAP/Lenis или звука. Системная и кабинетная настройки уменьшения анимации действуют совместно: числа сразу обновляются, график и перемещения отключаются. CSS учитывает оба режима.
