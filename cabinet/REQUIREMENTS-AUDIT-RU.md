Пользовательские ограничения: сначала публичная часть, затем кабинет; RU/ҚАЗ; сохранить основу и фирменные цвета; неизвестные проекты/людей не выдумывать; работа только над frontend.

## Состояние требований

| Требование | Реализовано | Осталось |
|---|---|---|
| Публичная основа | Главная, четыре карточки проектов, отдельный Young Diplomacy, пять коров и Google Form существуют | Внедрить публичные RU/ҚАЗ и фильтры во Framer; пакет текстов подготовлен |
| Проекты кабинета | Полный редактор RU/KK, категория/статус, состав/ответственный, создание, архив/восстановление, URL-фильтры | Подтвердить реальные статусы; неизвестные значения остаются незаполненными |
| Young Diplomacy | Самостоятельный клуб, Тарап Айша и Кайназарова Жасмин, Instagram, связанный Aspan | Реальная программа, будущие встречи и неизвестные медиа |
| Публичная команда | Честная заготовка, кабинет не подставляет демо-участников публично | Подтверждённый состав, биографии и разрешённые фотографии |
| Анкета | Все 22 вопроса, 4 шага, до двух департаментов, приоритеты, инструменты, навыки, портфолио, preview/черновик/уточнение/история | Редактура и утверждение названий/назначений командой; настоящая доставка — API |
| Профиль | Редактирование имени/описания/навыков, локальный аватар и preview; роль/кор отдельно | Настоящее постоянное файловое хранилище — backend |
| Команды | Самостоятельная модель, лидер, участники, связанные проекты, архив | Членство не даёт доступ к проекту автоматически |
| Задачи | Полный редактор и фильтры; начать → результат → возврат/подтверждение → единственное начисление; история и архив | Реальные поручения после подключения доверенных данных |
| Совместная работа | Комментарии, ответы, собственные правки и история, упорядоченный checklist | Realtime/многопользовательская доставка — API |
| Материалы | Категории/поиск, ссылки или файлы, preview/download, редактирование/архив, привязка к задаче | Настоящая облачная доставка — отдельный адаптер |
| XP | Графики/таблицы/журнал, месячный preview, ручной ранг с причиной, явное демо-закрытие прошедшего месяца | W1/W2 черновые, W3 и спорные награды не утверждены; автоматические санкции не придуманы |
| Предупреждения | Личные записи, выдача и закрытие в разрешённой области, причина/история | Организационные правила апелляции/санкций требуют клуба |
| Onboarding | Кандидат/участник, фактический прогресс, скрыть/возобновить | Настоящее состояние первого входа — API |
| Календарь/уведомления | Дедлайны Алматы, демонстрационные встречи, фильтры, повестка; прочитано/непрочитано и переход к объекту | Настоящее расписание и email/push не подключены |
| Управление | Проверка, заявки, назначения, проекты, команды, задачи, XP/предупреждения; обзор нагрузки, переход к фильтру, сохранённые представления | Серверное исполнение областей доступа — backend |
| Вход/регистрация/восстановление | Состояния frontend и демо-экраны | Настоящая auth/email/SMS — вне frontend-объёма |
| RU/ҚАЗ и адаптивность | Двуязычный кабинет, reduced motion, адресные браузерные проверки; 125 тестов | Редактор-носитель, расширенная приёмка реальных устройств/WCAG |
| Передача/размещение | Сборка, лицензии, SPA fallback, ZIP, инструкции и контракт | Кабинет опубликован на Vercel 17 октября; ссылка из Framer ещё не добавлена |

## Анкета

ФИО, дата рождения, телефон, место учёбы, класс/курс, языки, компьютер, Telegram, Instagram, email, пол, город/страна, до двух департаментов, приоритет 1, приоритет 2, программы/сервисы, навыки, опыт, мотивация, время в неделю, дополнительная информация, портфолио. Форма показывает условия для второго приоритета и локальное хранение файлов. Предыдущие короткие анкеты сохраняются как исторические записи.

Десять департаментов не заменены пятью корами. При принятии заявки назначение кора задаётся явно. Никакие новые реальные личные данные из Google-аккаунта в проект не переносились.

## Критерий завершения

Основные локальные сценарии этапов 0–10 реализованы и автоматически проверены. Наличие работающего демо не означает проверенную внешнюю платформу. Подробная выполненная проверка и её ограничения — `VERIFICATION-RU.md`; состояние остальных этапов — `IMPLEMENTATION-PROGRESS-RU.md`; контракт — `FRONTEND-HANDOFF-RU.md`.
