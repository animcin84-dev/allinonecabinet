# Размещение демоверсии кабинета

Публикуется самостоятельный frontend. Публичный сайт Allinone остаётся во Framer. Демоверсия содержит выдуманных участников и рабочие сценарии; настоящая авторизация и сервер пока не подключены. Действия каждого посетителя сохраняются только в его браузере: JSON в localStorage, файлы в IndexedDB. Эти данные не входят в static ZIP и не переносятся между доменами автоматически.

## Готовая сборка

Содержимое `dist` — файлы для static hosting. Архив `verification/allinone-cabinet-static.zip` содержит их в корне, включая `index.html` и правило `_redirects` для Netlify. Исходники, зависимости, скриншоты и данные браузерной проверки в архив не входят.

После изменения исходников повторить:

```sh
npm run check
npm run test
npm run build
npm run report:bundle
```

Архив нужно пересоздать из новой папки `dist`; старый архив автоматически не обновляется.

## Netlify

Для ручного размещения выбрать создание сайта из готовой папки и загрузить `dist` либо распакованное содержимое архива. При сборке из репозитория рабочая папка — `cabinet`, команда — `npm run build`, выходная папка — `dist`. Использовать Node.js 24+.

Файл `public/_redirects` переносится Vite в `dist`. Он позволяет открывать вложенные адреса напрямую: например, `/ru/app/tasks/task-01` и `/kk/app/projects/html?tab=tasks`.

Источник: [официальная документация Netlify для SPA](https://docs.netlify.com/build/configure-builds/javascript-spas/).

## Vercel

Корень проекта — `cabinet`, preset — Vite. Файл `vercel.json` задаёт сборку, выходную папку и возврат `index.html` для маршрутов приложения. Версия Node.js закреплена как `24.x` в package.json.

Источник: [официальная документация Vercel для Vite](https://vercel.com/docs/frameworks/frontend/vite).

## Проверка после размещения

1. Открыть `/ru/app`, затем напрямую `/ru/app/tasks/task-01` и обновить страницу. Они должны загружаться без 404.
2. Переключить язык на ҚАЗ. Проверить мобильное меню, поиск и график.
3. Пройти демо-цикл отправки и подтверждения задачи. После подтверждения XP начисляется один раз.
4. Проверить загрузку фотографий Aspan и AMUSE, отсутствие ошибок консоли и скорость на телефоне.
5. Добавить в навигацию Framer кнопку «Личный кабинет» с точным публичным адресом кабинета. Только после проверки адреса опубликовать это изменение во Framer.

Перед полноценным запуском клуба согласовать казахские тексты, соответствие десяти департаментов корам и черновые правила XP. Все 22 вопроса анкеты уже перенесены во frontend. Реальные аккаунты и личные данные подключаются отдельным этапом через backend.

Vercel завершил сборку со статусом READY. Проверены загрузка обзора, прямая ссылка `/ru/app/tasks/task-01` после обновления и переключение на ҚАЗ. Публичный сайт остаётся во Framer; кнопка из Framer на этот кабинет пока не добавлялась.
